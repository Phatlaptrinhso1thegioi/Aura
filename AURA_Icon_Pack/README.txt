AURA ICON PACK

app-icon/
  aura-app-icon-1024.png       Main AURA app icon artwork (1024x1024)

ui-icons/
  Individual SVG icons for navigation and player controls.

mood-icons/
  Individual SVG mood icons.

Usage:
- Copy the SVG files into the single aura.html file by embedding their SVG markup,
  or use them as separate assets during development.
- The PNG is the app icon artwork for the prototype / app icon reference.
- These are visual assets; browser HTML cannot install native iOS app icons or WidgetKit widgets.
